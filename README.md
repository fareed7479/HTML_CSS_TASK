# IRP LMS - Front-End Recreation (HTML5 & CSS3)

A responsive, pixel-accurate recreation of the **IRP LMS** platform built using clean, semantic **HTML5** and modern **CSS3**.

---

## 🚀 Live Pages Included

1. **Home Page (`index.html`)**:
   - Navigation bar with brand logo, nav links (with active state indicator), and outlined Sign In button.
   - Hero banner with category kicker (`LEARN • BUILD • GET PLACED`), orange highlight headline, value proposition copy, CTA button, and "Climbing Towards Success" artwork.
   - Five-step **Your Learning Journey** cards grid: *Learn, Practice, Build Projects, Prepare, Get Placed*.

2. **Courses Page (`courses.html`)**:
   - Courses hero banner with category kicker (`OUR COURSES`), headline, and e-learning artwork.
   - Responsive 3-column video tutorial grid featuring 9 embedded YouTube crash courses (HTML, CSS, JavaScript, React, Python, Java, Spring Boot, Hibernate, Django).
   - Responsive 16:9 video embed containers preventing black bars or letterboxing.
   - Bottom **Explore More Courses** banner with 9-dot grid icon and CTA button.

3. **Contact Us Page (`contact.html`)**:
   - Contact hero banner (`GET IN TOUCH` kicker, headline, and banner artwork).
   - Split two-column support layout:
     - **Contact Information Panel**: Direct email (`support@irplms.com`), phone (`+91 98765 43210`), and office address.
     - **Interactive Message Form**: Inputs for Full Name, Email Address, Subject selector, Message textarea, and full-width Send Message button.

## 💻 How to View & Run

1. Clone or download this repository.
2. Open any `.html` file directly in your preferred modern web browser (Chrome, Edge, Firefox, Safari).
3. Alternatively, run with VS Code's **Live Server** extension:
   - Right-click `index.html` and click **"Open with Live Server"**.
